# 부록 B. 전국 기도도량 465곳 오행 성향 색인

---

## 먼저 밝혀둘 것

**이 부록에는 465곳의 목록이 인쇄되어 있지 않다.** 그 이유를 정직하게 밝힌다.

### 이유 ① — 데이터에는 시차가 있다

제22장 5절에서 밝힌 그대로다. 사찰의 상황은 바뀐다. 주지 스님이 바뀌고, 전각이 서고, 문을 닫기도 한다. **인쇄된 목록은 인쇄된 순간부터 낡기 시작한다.**

전자책이라 해도 마찬가지다. 한 번 배포된 파일은 갱신되지 않는다. **틀린 정보를 고정된 형태로 남기는 것**은 이 책의 원칙에 어긋난다.

### 이유 ② — 순위는 사람마다 다르다

이것이 더 근본적이다. 제17장과 제27장에서 반복해 확인했다.

> **절대적으로 좋은 사찰은 없다. 순위는 사용자마다 새로 계산된다.**

그렇다면 **"465곳 순위표"라는 것은 애초에 존재할 수 없다.** 목록을 인쇄하는 순간, 그것은 이 책이 30개 장에 걸쳐 부정해 온 "명당 랭킹"이 되어버린다.

### 이유 ③ — 좌표는 추정값이다

제23장 5절에서 밝혔듯 사찰의 오행 좌표에는 **판단이 개입한다.** 이용자 제보로 계속 수정되는 값이기도 하다(제25장 6절). **수정될 값을 확정된 표로 박아두는 것**은 옳지 않다.

## 그럼 어떻게 찾는가

**웹 서비스에서 조회한다.** 이것이 유일하게 정직한 방법이다.

> **www.jamgong.kr**

거기서는

- 당신의 **용신 기준으로** 순위가 계산되고
- 각 도량의 **점수 내역**을 펼쳐볼 수 있으며
- **신뢰도 표시**(확인/참고/미확인)가 함께 나오고
- 데이터가 갱신되면 **결과도 갱신된다**

인쇄물이 줄 수 없는 것들이다.

---

## 대신 제공하는 것 — 직접 판별하는 법

목록 대신, **어떤 도량이든 스스로 읽는 방법**을 정리한다. 이것이 목록보다 오래 간다.

### 1단계 — 지형 읽기 (제23장)

| 관찰 | 오행 |
|---|---|
| 뒷산이 **곧게 솟았다** | 木 |
| 뒷산이 **뾰족하다** | 火 |
| 뒷산 능선이 **평평하다** | 土 |
| 뒷산이 **둥글다**, 바위가 많다 | 金 |
| 능선이 **물결친다**, 계곡·강이 가깝다 | 水 |

| 추가 관찰 | 가산 |
|---|---|
| 숲이 깊다 | 木 |
| 남향으로 트였다 · 고지대 | 火 |
| 평지·분지에 있다 | 土 |
| 암반이 많다 · 서향 | 金 |
| 물이 흐른다 · 저지대 | 水 |

### 2단계 — 본존·기도 읽기 (제24장)

| 본존 | 오행 | 근거 |
|---|---|---|
| 약사여래 | **木** | 동방정토 (경전 명시) |
| 아미타불 | **金** | 서방정토 (경전 명시) |
| 비로자나불 | 火 | 광명편조 (유추) |
| 석가모니불 | 土 | 중심·근본 (유추) |
| 지장보살 | 土 | 지장(地藏) (유추) |
| 관세음보살 | 水 | 감로수·해수관음 (유추) |
| 미륵불 | 木 | 미래·용화수 (유추) |

| 주 기도 | 오행 |
|---|---|
| 칠성기도 | **水** (북두칠성=북방) |
| 용왕기도 | 水 |
| 산신기도 | 土·木 |
| 인등·연등 | 火 |
| 천도재 | 水·土 |
| 건강 기도 | 木 |

### 3단계 — 나와 대조하기

1. 위 두 단계로 그 도량의 **우세 오행 두 개**를 뽑는다
2. 제14장에서 잡은 **나의 용신·희신·기신**과 비교한다

| 도량의 우세 오행이 | 판단 |
|---|---|
| 나의 **용신**이다 | 잘 맞는다 |
| 나의 **희신**이다 | 잘 맞는다 (간접 보강) |
| 나의 **기신**이다 | 지금 균형에는 도움이 적다 |
| 그 외 | 무난하다 |

**지형 판정에 더 큰 비중**을 두시라. 본존·기도는 근거가 상대적으로 약하다(제24장 5절).

## 이 방법의 쓸모

목록이 없다는 것이 불편해 보이지만, 실은 **더 넓게 쓰인다.**

- 465곳에 없는 절도 읽을 수 있다
- 여행 중 우연히 만난 암자도 읽을 수 있다
- **데이터가 낡아도 방법은 낡지 않는다**

제1장에서 "검증할 수 있게 만든다"고 했다. **목록을 주는 것보다 읽는 법을 주는 것**이 그 원칙에 더 가깝다고 판단했다.
