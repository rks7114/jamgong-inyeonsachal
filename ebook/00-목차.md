## 전체 목차 (12장)

### 제1부 — 왜 '데이터로 보는 인연사찰'인가

**제1장. 부적을 태우고 데이터를 켜다**
맹신적 마케팅의 해체 / "좋다더라"의 심리학 / 잼공인연사찰이 세운 세 가지 원칙 / 이 책을 읽는 법
→ *(전문 초안 완성: `chapters/01-제1장.md`)*

**제2장. 오행(五行)이란 무엇인가 — 미신이 아닌 관계의 언어**
木火土金水의 본질 / 상생(相生)과 상극(相剋)의 순환 / 오행을 '에너지 밸런스 지표'로 재해석하기 / 흔한 오해 바로잡기

**제3장. 나의 사주 읽는 법 — 생년월일시에서 오행 분포까지**
사주팔자의 구조(연·월·일·시주) / 천간지지와 오행 환산표 / 내 오행 분포 직접 계산해 보기 / 격국(格局)·용신(用神)의 개념 입문

### 제2부 — 잼공인연사찰의 기술: 5대 특허의 해부

**제4장. 인연사찰 매칭 엔진 — 방향성 관계행렬과 편차 감쇠형 시너지**
왜 단순 합산으로는 궁합을 못 재는가 / 방향성 관계행렬(directional relation matrix)의 아이디어 / 편차 감쇠형 비가산 시너지 연산의 직관적 설명 / 특허 1 해설

**제5장. 역법 AI 택일 — 기도·불공 날짜를 고르는 알고리즘**
전통 택일(擇日)의 논리 / 가중치 학습 AI 스케줄링이 하는 일 / '길일'을 확률로 환산하기 / 특허 2 해설

**제6장. 천체력 분석과 라이프사이클 지표**
천체력(ephemeris)과 사주의 접점 / 개인 라이프사이클 지표 생성 원리 / 시기별 오행 흐름 읽기 / 특허 3 해설

**제7장. 궁합 감성지수와 꿈해몽 AI**
다중 모달 감성 동기화 지수(궁합 감성지수) / 다중 벡터 임베딩 기반 꿈해몽 AI / 감성 데이터를 역학과 연결하는 법 / 특허 4·5 해설

### 제3부 — 전국 사찰 DB와 나의 도량 찾기

**제8장. 17,497곳의 지도 — 전국 사찰 데이터베이스의 구조**
사찰 DB 17,497곳 / 기도도량 465곳 / 상세정보 702곳 / 데이터가 만들어지는 과정과 신뢰성

**제9장. 나에게 맞는 사찰 매칭 실전 가이드**
오행 부족·과잉별 도량 성향 / 산세·본존불·기도 종류로 보는 매칭 / 웹 서비스로 3분 만에 내 인연사찰 찾기 / 실제 매칭 사례 5선

### 제4부 — 오행 균형과 개운(開運), 그리고 잼공몰

**제10장. 개운법의 재정의 — '운을 바꾼다'는 말의 진짜 의미**
개운(開運)을 미신에서 습관과 환경 설계로 옮기기 / 오행 균형을 일상에서 맞추는 법 / 색·방위·소재의 오행 매핑

**제11장. 기도용품, 오행으로 고르다 — 잼공몰 큐레이션의 논리**
왜 '아무 염주'나 사면 안 되는가 / 오행별 맞춤 기도용품 매칭 로직 / 향·초·염주·불전함의 오행 속성 / 잼공몰 큐레이션 활용법

**제12장. 100일의 실천 — 나만의 인연사찰 순례 플랜**
데이터로 시작해 습관으로 완성하기 / 100일 기도·순례 실천 캘린더 / 회고와 재조정 루프 / 맺음말: 맹신이 끝나는 곳에서 정성이 시작된다
