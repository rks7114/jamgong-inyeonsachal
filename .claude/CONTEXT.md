# 잼공인연사찰 도메인 용어사전

## 핵심 개념
- **인연사찰**: 사주의 오행을 기반으로 개인의 기운과 맞는 사찰 추천
- **궁합사찰**: 두 사람의 사주 궁합을 분석해 어울리는 사찰 추천
- **오행(五行)**: 금(金), 목(木), 수(水), 화(火), 토(土)

## 사주 분석
- **취약원소**: 사주에서 부족한 오행 원소
- **용신**: 사주 균형을 맞추는 데 필요한 원소
- **납음오행**: 음양오행학의 오행 배합 규칙

## API 엔드포인트
- **api/match.js**: 단일 인연사찰 매칭 (목표 성능: 11.7ms)
- **api/match-couple.js**: 궁합사찰 분석 (목표 성능: 16.6ms)
- **api/saju.js**: KASI 천체력 데이터

## 매칭 기준
- **점수 구성**: 방위 적합도(최대 40) + 목적 태그(최대 30) + 신뢰도(최대 13) + 개인 공명(최대 20) + 생년월일 친연도(±30) + 시너지 보너스 — 추천 최소 기준 50점
- **거리 계산**: Haversine 공식 (최종 3곳만 지연 계산)
- **거리점수**: 0으로 고정 — 거리는 점수에 반영하지 않음 (전국 동등 경쟁, 표시용으로만 계산)

## 검색 최적화
- **디바운스**: 150ms (키 입력 지연)
- **결과 제한**: 60건 표시 + 전체 개수 표시
- **중복 제거**: id 기준 (DB 중복 3,484건 처리)

## 성능 목표
- matchTemples: 11.7ms 이하
- matchCoupleTemples: 16.6ms 이하
- 검색 응답: 20ms 이하
