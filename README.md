# 잼공인연사찰 (MVP v0.1)

생년월일시 기반 오행 분석으로 인연이 닿는 사찰을 추천하는 서비스. 잼공스토리 브랜드 계열, 잼공 오라클과는 독립 운영.

## 현재 상태
- ✅ 오행 매칭 로직 (`src/matching-engine.js`) — 동작 검증 완료
- ✅ MVP 프론트엔드 (입력폼 → 나침반 시각화 → 추천 3곳)
- ✅ Vercel Serverless API (`api/match.js`)
- ✅ 사주 계산: `lunar-javascript`(6tail) 라이브러리로 절기 기준 정밀 만세력 계산 완료
- ✅ 위치 자동감지: 브라우저 Geolocation API 연동 완료 (거부/미지원 시 서울시청 폴백)
- ✅ **사찰 DB: 행정안전부_문화_전통사찰 공식 데이터 1,905건 연동 완료** (`src/temple-db.full.js`)
  - 좌표 확보: 1,494건 (78%) / 좌표 미확보 411건은 매칭에서 자동 제외 (주소만 있음)
  - 유래연혁·창립연대 확보: 1,500건 (79%) → `verified: true`로 표시, 매칭 시 신뢰도 점수 우대
  - 좌표계: EPSG:2097(Bessel 중부원점TM, 보정계수 없음) → WGS84 변환 완료
  - 출처: 공공데이터포털, 이용허락범위 제한 없음 (상업적 이용 가능)
  - 검수용 정제본: `전국사찰_정제본.xlsx` 별도 첨부 (전체 필드 확인 가능)

## 회장님이 하실 일 (배포)

1. **GitHub 레포 생성**: `jamgong-inyeonsachal` (또는 원하시는 이름)
2. 이 폴더 전체를 레포에 push
3. **Vercel 대시보드**에서 해당 레포 Import → 자동 배포 (메디컴퍼스 때와 동일 절차)
4. 별도 환경변수 설정은 아직 불필요 (Gemini 연동은 다음 단계에서 추가)
5. 

```bash
# 로컬 테스트 (선택)
npm install
npm run dev
```
