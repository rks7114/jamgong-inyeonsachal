# jamgong-saju-core

잼공 전 서비스가 공용으로 쓰는 사주만세력 엔진. 잼공인연사찰에서 검증된 로직을 분리했습니다.

## 왜 분리했나

지금까지는 잼공인연사찰 안에 사주 계산 코드가 묶여 있었습니다. 이대로 두면 나중에 잼공오라클, 잼공궁(택일)을 만들 때 사주 계산을 각자 다시 짜야 하고, 그러면 서비스마다 계산 결과가 미세하게 달라질 위험이 있습니다.

이 모듈 하나로 통일하면:
- 잼공인연사찰 / 잼공오라클 / 잼공궁 모두 **동일한 정확도**의 사주 계산을 씀
- 만세력 로직에 버그가 생기거나 개선이 필요할 때 **한 곳만 고치면 전 서비스에 반영**
- 새 서비스를 만들 때 사주 계산을 매번 새로 안 짜도 됨

## 제공 함수

```js
const saju = require('jamgong-saju-core');

// 사주 팔자 원본 객체 (천간/지지, 오행 등 세부 조회 가능)
const bazi = saju.getEightChar('1980-05-20T10:00:00');

// 오행 분포 { 목:2, 화:1, 토:2, 금:2, 수:1 }
const distribution = saju.calculateOhaeng('1980-05-20T10:00:00');

// 가장 부족한 오행
const weak = saju.findWeakOhaeng(distribution);

// 특정 오행과 일치하는 일진 날짜 추천 (택일에 활용)
const dates = saju.getRecommendedDates('화', 30, 5);
```

## 현재 상태

- ✅ 잼공인연사찰에서 실사용 검증 완료 (1,905개 사찰 매칭에 적용 중)
- ⏳ 잼공오라클·잼공궁 연동은 차후 진행 (오라클 본체가 아직 개발 중이라 대기)

## 연동 방법 (오라클/택일 완성 후)

1. 이 폴더를 별도 GitHub 저장소(`jamgong-saju-core`)로 올리기
2. 각 서비스에서 `npm install github:rks7114/jamgong-saju-core` 형태로 의존성 추가
   (또는 사설 npm 레지스트리를 쓰신다면 그쪽에 배포)
3. 각 서비스의 자체 사주 계산 코드를 이 모듈 호출로 교체
