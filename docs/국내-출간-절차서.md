## 남은 절차 — 다섯 단계

### 1단계 · 두 값을 정한다 — 회장님 (5분)

```
발행일 2026-08-15
정가 19900
```

이 두 줄을 저에게 주시면 됩니다.

| | 정하는 기준 |
|---|---|
| **발행일** | 부크크 심사가 2~3일. **일주일 뒤**로 잡으면 여유롭습니다 |
| **정가** | **19,900원** 권합니다. 112,746자는 단행본 이상이고, 종이책 18,000~20,000원대에 대응합니다 |

받으면 제가 이렇게 처리합니다.

```bash
python ebook/set_colophon.py --date 2026-08-15 --price 19900
python ebook/build_all.py
```

판권표와 EPUB `dc:date`가 동시에 바뀌고, 12개 판본이 다시 구워집니다.

### 2단계 · 부크크 등록 — 회장님 (30분)

**왜 부크크인가.** ISBN을 **무료로 대행**하고, 등록하면 **교보·알라딘·예스24에 자동 유통**되며, 초기 비용이 **0원**입니다.

```
① 부크크 가입          사업자 330-34-01680
② 전자책 만들기 → EPUB 업로드
③ 도서정보 입력        ← 판매패키지.md 3절을 그대로 복사
④ 표지 업로드
⑤ 가격 입력 → 심사 신청
```

**②④에 넣을 파일**

| | 경로 |
|---|---|
| 본문 | `ebook/dist/소문을끄고데이터를켜다.epub` |
| 표지 | `ebook/dist/` 안의 표지 이미지 |
| 미리보기 | `ebook/dist/소문을끄고데이터를켜다-미리보기.epub` (전체의 7.5%) |

**③에 넣을 문안** — `ebook/sales-page/판매패키지.md` 3절에 도서명·부제·지은이·분류·소개 400자가 그대로 있습니다.

### 3단계 · 심사 대기 (2~3일)

반려될 일은 거의 없습니다. `check_epub.py`로 규격을 미리 봤고 반려 사유가 0건입니다.

만약 반려되면 사유를 그대로 주십시오. 대개 표지 규격이나 메타데이터 문제이고 반나절이면 고칩니다.

### 4단계 · ISBN 반영 — 회장님 한 줄 + 제가 처리 (10분)

심사가 통과되면 ISBN이 나옵니다. 그 번호를 주시면 됩니다.

```bash
python ebook/set_colophon.py --isbn 979-11-XXXX-XXX-X
python ebook/build_all.py
```

판권과 **EPUB 식별자**가 함께 바뀝니다(`urn:uuid:…` → `urn:isbn:…`). 유통사는 ISBN을 식별자로 기대하므로, 판권만 고치고 파일을 두면 어긋납니다.

**이 시점에 검수가 34/34가 됩니다.** 그것이 국내 완료 신호입니다.

바뀐 EPUB을 부크크에 다시 올리시면 됩니다.

## 홍보는 별개로 막혀 있습니다

출간과 무관하게, **홍보 발행이 안 됩니다.**

```
automation/logs/threads_2026-07.jsonl
  4건 전부  status: dry_run  reason: no_credentials
```

글은 만들어지는데 나가지 않습니다. 필요한 것은 둘입니다.

1. **Threads 앱 검수** — 메타에서 `threads_content_publish` 권한
2. **`THREADS_USER_ID` · `THREADS_ACCESS_TOKEN`**

**토큰은 채팅에 붙여넣지 마십시오.** 대화 기록에 남습니다. 서버의 `automation/.env`에 직접 넣으시면 코드는 손댈 것 없이 실제 발행으로 넘어갑니다.

30일치 홍보글은 이미 `automation/threads/queue.jsonl`에 쌓여 있습니다.
