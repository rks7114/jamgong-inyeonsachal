# 잼공인연사찰 & 잼공몰 완전 자동화 시스템 — 개요 및 진행 현황

- **서비스:** 잼공인연사찰 (JAMGONG INYEONSACHAL) · https://www.jamgong.kr
- **핵심 철학:** 맹신적 마케팅(부적·"카더라") 배제 → 생년월일시 사주 오행(木火土金水) 분석과 역학적 궁합(격국·용신·합충) 기반의 객관적 매칭 인프라.
- **목표:** AI가 기획·집필·상세페이지·SNS 홍보·24시간 도반 소통·가격 제안까지 스스로 도는 **Full-Auto Loop** 구축.

---

## 3단계 실행 과제 · 진행 현황

| 단계 | 과제 | 산출물 | 상태 |
| --- | --- | --- | --- |
| **Step 1** | 전자책 자율 집필 + 퍼블리싱 | `ebook/` — 8부 30장 + 부록 7종(약 102,000자), 상세페이지 카피, `build_epub.py`(EPUB 3 빌더), `automation/manuscript/progress.py`(트래커) | ✅ **완료** |
| **Step 2** | 플랫폼·잼공몰 락인 퍼널 | `funnel/cta_injector.py`(멱등 CTA 삽입), `ohang_product_map.json`(오행→상품), 전 장 UTM 부착 | ✅ **완료** |
| **Step 3** | 24시간 홍보·소통·회고 | `automation/threads/`(발행), `automation/qa-agent/`(응대 29항목), `automation/analytics/`(회고), `crontab.example` | ✅ 스캐폴딩 완료 / ⚪ 실 API 자격증명 주입 대기 |

### 부가 산출물

| 도구 | 역할 |
| --- | --- |
| `funnel/ohang_calculator.py` | 제8장 오행 분포 계산 검산기 |
| `funnel/matcher.py` | 제17~19장 매칭 엔진 참조 구현 (관계행렬·감쇠·시너지) |
| `ebook/build_epub.py` | 의존성 없는 EPUB 3 변환기 (표지 SVG 포함) |
| `ebook/render_cover.py` | 같은 표지 소스를 판매용 PNG(1707×2560)로 래스터화 |
| `ebook/build_html.py` | 전용 뷰어 없이 브라우저에서 읽는 단일 HTML 생성 |

두 검산기는 본문 수치와 일치함을 확인했으며, 독자가 계산을 직접 검증할 수 있게 하는 것이 목적입니다.

## 지금 바로 확인 가능한 것

```bash
python automation/manuscript/progress.py                      # 집필 진척 (30/30)
python ebook/build_epub.py                                    # EPUB 생성
python funnel/ohang_calculator.py                             # 오행 계산 검산
python funnel/matcher.py --yongsin 火                         # 매칭 엔진 (용신별 재계산)
python funnel/cta_injector.py --dry-run                       # CTA 삽입 미리보기
python automation/threads/post_scheduler.py --dry-run         # 홍보글 미리보기
python automation/qa-agent/qa_agent.py "이거 미신 아닌가요?"   # 도반 응대
python automation/analytics/daily_report.py                   # 일일 회고
```

## 설계 원칙 (전 단계 공통)
- 근거 없는 것은 팔지도 말하지도 않는다.
- 모든 매칭·응대는 검증·재현 가능해야 한다.
- 외부 발행/가격 변동은 안전 기본값(자격증명 없으면 dry-run, 가격은 '제안'만) 위에서만.
