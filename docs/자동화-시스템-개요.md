# 잼공인연사찰 & 잼공몰 완전 자동화 시스템 — 개요 및 진행 현황

- **서비스:** 잼공인연사찰 (JAMGONG INYEONSACHAL) · https://jamgong-inyeonsachal.vercel.app
- **핵심 철학:** 맹신적 마케팅(부적·"카더라") 배제 → 생년월일시 사주 오행(木火土金水) 분석과 역학적 궁합(격국·용신·합충) 기반의 객관적 매칭 인프라.
- **목표:** AI가 기획·집필·상세페이지·SNS 홍보·24시간 도반 소통·가격 제안까지 스스로 도는 **Full-Auto Loop** 구축.

---

## 3단계 실행 과제 · 진행 현황

| 단계 | 과제 | 산출물 | 상태 |
| --- | --- | --- | --- |
| **Step 1** | 전자책 자율 집필 + 퍼블리싱 세팅 | `ebook/00-목차.md`(**8부 30장** 목차), `ebook/chapters/`(1~2장 전문), `ebook/sales-page/상세페이지-카피.md`, `automation/manuscript/progress.py`(진척 트래커) | 🟢 30장 목차·1~2장·상세페이지·트래커 완료 / ⚪ 3~30장 집필 대기 |
| **Step 2** | 플랫폼·잼공몰 락인 퍼널 | `funnel/cta_injector.py`(CTA 자동 삽입), `funnel/ohang_product_map.json`(오행→상품 매핑) | 🟢 완료(멱등 검증) |
| **Step 3** | 24시간 홍보·소통·회고 파이프라인 | `automation/threads/`(스레드 발행), `automation/qa-agent/`(도반 Q&A), `automation/analytics/`(셀프 회고), `automation/crontab.example` | 🟢 스캐폴딩 완료(dry-run 동작 검증) / ⚪ 실 API 자격증명 주입 대기 |

---

## 지금 바로 확인 가능한 것 (모두 로컬에서 실행됨)

```bash
python automation/manuscript/progress.py                      # Step 1: 30장 집필 진척 확인
python funnel/cta_injector.py --dry-run                       # Step 2: CTA 삽입 미리보기
python automation/threads/post_scheduler.py --dry-run         # Step 3: 홍보글 미리보기
python automation/qa-agent/qa_agent.py "이거 미신 아닌가요?"   # Step 3: 도반 응대
python automation/analytics/daily_report.py                   # Step 3: 일일 회고
```

> 상세 운영법은 `automation/README.md` 참고.

## 다음 스텝 (권장 순서)

1. **전자책 3~30장 집필** — 1~2장과 동일한 톤/구조로 이어서 작성. `progress.py --next` 로 다음 대상을 확인하고, 각 장 완료 시 `funnel/cta_injector.py` 실행으로 CTA 자동 부착.
2. **자격증명 주입** — `automation/.env` 에 Threads 토큰, (선택) Anthropic 키 설정 → dry-run 해제.
3. **Q&A 실서비스 연결** — `qa_agent.answer()` 를 웹 위젯/웹훅/서버리스로 감싸 배포.
4. **크론 등록** — `crontab automation/crontab.example` (경로 수정 후).
5. **전자책 퍼블리싱** — 상세페이지 카피로 디지털 판매 플랫폼(래피드 등) 등록, 제1장 무료 리드마그넷 공개.

## 설계 원칙 (전 단계 공통)
- 근거 없는 것은 팔지도 말하지도 않는다.
- 모든 매칭·응대는 검증·재현 가능해야 한다.
- 외부 발행/가격 변동은 안전 기본값(자격증명 없으면 dry-run, 가격은 '제안'만) 위에서만.
